# Oxygen Delivery Evidence

**Living Scientific Repository**

Evidence, context and analysis across human medicine, veterinary medicine, transplantation and oxygen biology.

## Purpose

Oxygen Delivery Evidence is a broader scientific evidence layer for research on oxygen delivery and its limitations. It is intentionally separate from direct BHOC / HBOC evidence repositories.

The repository is designed to organize evidence on:

- transfusion and donor blood
- tissue oxygenation
- hypoxia and ischemia
- microcirculation
- mitochondria
- nitric oxide biology
- oxygen sensing and HIF
- hemolysis and free heme
- organ perfusion
- blood storage
- compatibility and alloimmunization
- shock and resuscitation
- comparative oxygen-delivery strategies

## Initial veterinary collection

The first collection focuses on veterinary transfusion, Oxyglobin, HBOC, tissue oxygenation, transfusion reactions and alloimmunization.

The repository stores metadata, identifiers, structured summaries and links to original sources. It does not republish copyrighted journal articles unless reuse is explicitly permitted.
