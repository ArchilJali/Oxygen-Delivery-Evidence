# Security Policy

## Reporting a security issue

Do not disclose suspected vulnerabilities, credentials, private keys, personal data, patient data, confidential partner information, or exploitation details in a public issue.

Report concerns privately to `info@bhoctherapeutics.com` with the affected file or URL, reproduction steps, impact, and supporting evidence.

## Public-data boundary

This is a public scientific repository. Every committed file must be safe for public access. Store only publication metadata, identifiers, structured summaries, original analyses, and links that are appropriate for publication.

## Supported version

Security and data-integrity fixes apply to the current `main` branch.
