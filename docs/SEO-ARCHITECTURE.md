# SEO and Public Architecture

## Public identity

**Oxygen Delivery Evidence**  
Living Scientific Repository

Recommended palette:
- Deep navy: #10243E
- Scientific cyan: #1687A7
- Cool background: #F5F8FA
- Graphite: #26333D

The palette should remain visually distinct from BHOC Veterinary orange.

## Curated indexable pages

Recommended: `/human/`, `/veterinary/`, `/transplant/`, `/topics/transfusion/`, `/topics/tissue-oxygenation/`, `/topics/ischemia/`, `/topics/hypoxia/`, `/topics/microcirculation/`, `/topics/mitochondria/`, `/topics/alloimmunization/`, `/perspectives/`.

Arbitrary filter combinations should not create unlimited indexable URLs. Search result pages should normally be `noindex` unless curated as canonical landing pages.

Each publication should have one canonical record page. Topic and domain views should link to that record rather than duplicate the full content.

Public websites should link to public evidence pages, not GitHub code repositories, except in a small Methodology or Version History context.
